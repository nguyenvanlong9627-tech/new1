Không Thể Mở Camera Trực Tiếp

Trình duyệt di động hoặc khung webview đang chặn quyền truy cập trực tiếp vào ống kính camera.

Cách khắc phục nhanh trên điện thoại:
  • Sử dụng tùy chọn "Tải Clip / Quay Video": Trình duyệt sẽ mở ứng dụng Camera máy điện thoại của bạn để quay video xe rồi phân tích.
  • Đảm bảo trang web đang chạy qua liên kết https://.
  • Mở bằng trình duyệt **Safari** hoặc **Chrome** gốc thay vì xem qua ứng dụng thứ 3.

Hiệu Chỉnh Thông Số Đo Khoảng Cách (Camera Calibration)

Khoảng cách được tính toán bằng mô hình hình học Camera Lỗ Kim (Pinhole Camera Model). Bạn cần thiết lập tiêu cự cảm biến $f$ để đảm bảo độ chính xác.

Công thức tính toán:
Distance (D) = ( Focal Length (f) × Real Vehicle Width (W) ) / Pixel Width (w)

• f (Focal Length): Tiêu cự tính bằng pixel của camera (iPhone khuyên dùng $f = 700 - 850\text{ px}$).
• W (Real Width): Chiều rộng trung bình của xe thực tế (Ô tô ≈ 1.8m, Xe tải/Bus ≈ 2.5m, Xe máy ≈ 0.8m).
• w (Pixel Width): Chiều rộng khung nhận diện xe phát hiện bởi AI trong ảnh (pixels).

* Mẹo cho iPhone: Camera chính 1x chuẩn thường có tiêu cự calib khoảng 700 - 850 px.

Mét (m)

Độ rộng ước tính của xe con sedan/SUV thông thường.

Cách tự Calib thực tế với xe của bạn:

  1. Đặt điện thoại/camera trên xe ô tô của bạn, đỗ xe đằng sau một chiếc ô tô khác ở khoảng cách chính xác 10 mét (đo bằng thước dây hoặc máy đo laser).
  2. Bật ứng dụng ở chế độ Camera Trực Tiếp.
  3. Kéo thanh trượt Focal Length (f) sao cho thông số khoảng cách trên màn hình hiển thị đúng số 10.0 m.
  4. Lưu lại chỉ số tiêu cự đó!

Hướng Dẫn Tự Làm Thiết Bị Đo Khoảng Cách Thực Tế

Để biến ý tưởng này thành một thiết bị gắn trực tiếp lên kính lái ô tô thật (sử dụng Python + Raspberry Pi hoặc Jetson Nano), bạn cần chuẩn bị các phần dưới đây.

1. Phần Cứng (Hardware)
  • Bo mạch xử lý: Raspberry Pi 4 (4GB RAM) hoặc NVIDIA Jetson Nano.
  • Camera: WebCam USB HD (1080p, góc nhìn 60°-90°).
  • Màn hình HUD: Màn hình cảm ứng LCD 5-7 inch đính kính lái.
  • Còi cảnh báo: Buzzer 5V hoặc loa mini Jack 3.5mm.
  • Cấp nguồn: Tẩu sạc ô tô USB Type-C 5V-3A.
2. Phần Mềm (Software)
  • Hệ điều hành: Raspberry Pi OS / Ubuntu Linux.
  • Ngôn ngữ: Python 3.10+.
  • Thư viện AI/CV: OpenCV (`opencv-python`), Ultralytics YOLOv8 (`ultralytics`), PyTorch.
  • Mô hình AI: YOLOv8n (YOLOv8 Nano - chạy 30-60 FPS trên máy nhúng).
3. Cảm Biến Bổ Sung
  • LiDAR 1D TFmini Plus: Đo khoảng cách bằng Laser chính xác tuyệt đối ban đêm (độ xa 12m).
  • Cảm biến Radar mmWave 24GHz: Hoạt động hoàn hảo cả khi mưa bão, sương mù.
  • OBD-II Dongle: Đọc tốc độ xe hiện tại qua cổng OBD2 để tính TTC.

Mã Nguồn Python Minh Họa (OpenCV + YOLOv8) 

import cv2
import math
from ultralytics import YOLO

# 1. Tải mô hình AI YOLOv8
model = YOLO('yolov8n.pt')

FOCAL_LENGTH = 700   # Tiêu cự camera (pixels)
REAL_CAR_WIDTH = 1.8 # Chiều rộng ô tô (meters)
VEHICLE_CLASSES = [2, 3, 5, 7] # car, motorcycle, bus, truck

# Giả lập tốc độ xe từ OBD-II / GPS (km/h)
current_speed_kmh = 65.0 

cap = cv2.VideoCapture(0)

while cap.isOpened():
    ret, frame = cap.read()
    if not ret:
        break

    # Tính khoảng cách an toàn tối thiểu quy định theo tốc độ
    # Quy định: Tốc độ > 60 km/h -> Khoảng cách an toàn tối thiểu = 60m
    if current_speed_kmh > 60:
        min_safe_distance = 60.0
        danger_distance = 30.0
    else:
        min_safe_distance = 15.0
        danger_distance = 8.0

    results = model(frame, stream=True)

    for r in results:
        boxes = r.boxes
        for box in boxes:
            cls = int(box.cls[0])
            if cls in VEHICLE_CLASSES:
                x1, y1, x2, y2 = map(int, box.xyxy[0])
                pixel_width = x2 - x1

                if pixel_width > 0:
                    distance = (REAL_CAR_WIDTH * FOCAL_LENGTH) / pixel_width

                    if distance < danger_distance:
                        color = (0, 0, 255) # Đỏ - NGUY HIỂM!
                        label_status = f"DANGER! (<{danger_distance:.0f}m)"
                    elif distance < min_safe_distance:
                        color = (0, 165, 255) # Cam - Chú ý giữ khoảng cách quy định
                        label_status = f"WARNING (<{min_safe_distance:.0f}m)"
                    else:
                        color = (0, 255, 0) # Xanh - An toàn
                        label_status = "SAFE"

                    cv2.rectangle(frame, (x1, y1), (x2, y2), color, 2)
                    text = f"{distance:.1f}m | {label_status} | Speed: {current_speed_kmh:.0f}km/h"
                    cv2.putText(frame, text, (x1, y1 - 10),
                                cv2.FONT_HERSHEY_SIMPLEX, 0.5, color, 2)

    cv2.imshow("ADAS Speed-Adaptive Collision Warning", frame)

    if cv2.waitKey(1) & 0xFF == ord('q'):
        break

cap.release()
cv2.destroyAllWindows()
